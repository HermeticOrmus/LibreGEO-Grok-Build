# Schema Markup (GEO)

Use appropriate schema.org types honestly.

## Steps
1. Identify entity type (Organization, SoftwareApplication, Article, FAQ…).
2. Map required/recommended properties.
3. Prefer JSON-LD; validate mentally against docs.
4. Do not invent ratings or reviews.
5. Ship only accurate structured data.
