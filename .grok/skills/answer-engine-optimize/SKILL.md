# Answer Engine Optimize

Structure for extraction, not keyword abuse.

## Steps
1. Lead with a direct answer paragraph.
2. Support with bullets / steps / tables.
3. Add FAQ only when questions are real.
4. Keep headings descriptive.
5. Reject stuffing and deceptive markup.
